# ИЗВНЕ Mafia Bot

Телеграм-бот для игры в стиле мафии с закрепленной панелью в чате, ночными ходами в личке и деплоем на Render.

## Команды
- `/start` — открыть набор или войти в игру
- `/stopgame` — остановить игру
- `/info` — показать помощь
- `/extend` — продлить набор ещё на 2 минуты

## Что делает бот
- создает и обновляет закрепленную панель в групповом чате
- держит набор 5 минут
- раздает роли в личные сообщения
- ночью дает кнопки для хода активным ролям
- автоматически переключает ночь/день по таймеру

## Роли
- Мирный
- Тень (мафия)
- Проводник (доктор)
- Наблюдатель (комиссар)

## Как запустить локально
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN=YOUR_TOKEN
python bot.py
```

## Как залить на Render
1. Создай бота через `@BotFather`.
2. Загрузи эти файлы в GitHub.
3. На Render создай **Background Worker** или импортируй `render.yaml`.
4. Добавь переменную окружения `BOT_TOKEN`.
5. Запусти деплой.

## Важно
- Боту нужна админка в группе, чтобы закреплять сообщение-панель.
- Каждый игрок должен открыть личку с ботом, иначе роль в ЛС не придет.
- В этой версии дневное голосование не реализовано. Игра циклично идет `ночь -> день -> ночь`.
- Если захочешь, следующей итерацией можно добавить:
  - дневное голосование
  - изгнание игрока
  - несколько мафиози с общим решением
  - web-panel / mini app
  - PostgreSQL вместо SQLite
